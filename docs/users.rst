Florin is a Smart Contract deployed to Robinhood Chain that lets you borrow Florin US
Dollars (FUSD) in exchange for Stock Tokens.

Let's dive into what this all means:


Robinhood Chain
---------------

Robinhood Chain is an Arbitrum-based blockchain. A blockchain is a computer system that
runs smart contracts. A smart contract is code that cannot be changed due to being
immutable that's run on the blockchain.

Smart contracts can interact with each other, by sending each other money and more.

Arbitrum is the leading blockchain technology for financial application smart contracts,
and at the time of writing has $2.227 USD billion worth of value deployed across a
plethora of smart contracts on various chains Arbitrum runs, including Robinhood Chain.

Stock Tokens
------------

Stock Tokens are stocks provided by Robinhood (the company) that are converted to smart
contracts. These smart contracts have ideas of balance, approving other smart contracts to
use them, and sending them.

Florin is a smart contract deployed to Robinhood Chain. A website has been built that lets
you connect to the smart contract, and the website runs at https://florin.so.

What are Florin US Dollars?
---------------------------

When the S&P500 ETF and other Stock Tokens are supplied to Florin, Florin sends a US
dollar-denominated token that can be exchanged for the underlying collateral
