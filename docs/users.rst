Florin For Borrowers
====================

Florin is an application deployed to Robinhood Chain that lets you borrow Florin US
Dollars (FUSD) in exchange for Stock Tokens.

Let's dive into what this all means:

Robinhood Chain
---------------

Robinhood Chain is an Arbitrum-based blockchain. A blockchain is a computer system that
runs smart contracts. A smart contract is a piece of code that can't be changed. Smart
contracts can interact with each other. Arbitrum is the leading blockchain technology for
financial applications, and at the time of writing has $2.227 USD billion worth of value
deployed across a plethora of smart contracts on various chains, including Robinhood Chain.

Stock Tokens
------------

Stock Tokens are stocks provided by Robinhood (the company) that are converted to be used with smart contracts. They are held by wallets.

Florin is a smart contract deployed to Robinhood Chain. A website has been built that lets
you connect to the smart contract, and the website runs at https://florin.so.
